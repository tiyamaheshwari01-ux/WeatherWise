# 🌦️ WeatherWise — Weather Forecasting & Analytics
URL-(https://weatherwise-3aoypvgyfmubkxvrl4rec8.streamlit.app/)
source(data set) -https://open-meteo.com/en/docs
**WeatherWise** is a weather analytics and forecasting dashboard developed as a Data Mining and Data Warehousing mini-project. It combines historical weather data, machine learning algorithms, data visualization, and a star-schema data warehouse in one interactive application.

## 🎯 Project Objectives

- Analyze historical weather patterns.
- Predict next-day maximum temperature using **Linear Regression**.
- Classify next-day rainfall using **Random Forest Classifier**.
- Store and organize weather data using a **Star Schema**.
- Visualize weather trends and model performance through an interactive dashboard.

## ✨ Key Features

- 📊 Interactive weather analytics dashboard
- 🌡️ Temperature prediction
- 🌧️ Rainfall classification
- 📈 Historical weather trend visualization
- 🗄️ SQLite data warehouse
- 🤖 Machine learning model evaluation
- 🌐 Web interface built with Streamlit

## 🧠 Machine Learning Algorithms

**1. Linear Regression**  
Used to estimate the next day's maximum temperature from historical weather features.

**2. Random Forest Classifier**  
Used to classify whether next-day precipitation is likely to exceed the selected 1 mm threshold.

Model performance is evaluated using appropriate regression and classification metrics.

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/tiyamaheshwari01-ux/WeatherWise.git
cd WeatherWise
```

**2. Create and activate a virtual environment**

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the data pipeline**

```bash
python src/data_pipeline.py
```

**5. Train the machine learning models**

```bash
python src/train_models.py
```

**6. Launch the dashboard**

```bash
python -m streamlit run main.py
```

## 📂 Data Warehouse Design

WeatherWise uses a **Star Schema** in SQLite:

- **Dim_Date:** Stores date-related attributes.
- **Dim_Location:** Stores location details.
- **Fact_Weather:** Stores measurable weather observations linked to the dimensions.

This structure supports organized storage and analytical queries.

## 📏 Evaluation Metrics

- **Regression:** Mean Absolute Error (MAE) and Root Mean Squared Error (RMSE).
- **Classification:** Accuracy, Precision, and Recall.

Actual performance values are generated by the training pipeline and stored in `models/metrics.json`.

## ⚠️ Disclaimer

Weather predictions are educational estimates based on historical data and trained models. They should not be treated as official real-time weather forecasts.
